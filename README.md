# zomato-restaurants-analysis-python-sql-powerbi

## 📌 Project Overview
This project focuses on analyzing Zomato restaurant data to understand customer demand hotspots, restaurant performance, pricing trends, and service availability across different cities and locations.

The analysis is presented using an interactive Power BI dashboard with filters and business KPIs.

---

## 🛠 Tools Used
- *Python* - data cleaning , removing duplicates
- *SQL (MySQL)* – data analysis, KPI queries
- *Power BI* – dashboard, visuals, slicers
- *Excel/CSV* – data source (cleaned dataset)

---

## 📊 Dataset Information
### Key Columns:
- name
- online_order
- book_table
- rate
- votes
- location
- rest_type
- cuisines
- cost
- type
- city

---

## 📈 Key KPIs
- Total Restaurants
- Total Votes
- Average Cost (for two)
- Average Rating

---

## 🔍 Key Insights
- Identified *Top 10 cities* with maximum restaurants.
- Found *demand hotspot locations* using customer votes.
- Evaluated relationship between *restaurant cost and customer ratings* (scatter plot).
- Analyzed restaurant distribution by *restaurant type*.
